# 来源与范围

本包的教学文字、合成港口/维修活动资料、学生接口、标准库适配器和公开练习由本轮为《皮皮和汤圆 Python 学习游戏》原创编写。它借鉴用户提供的 AE26 C00–C04、E00、KRESEARCH 中关于检索、引用、记忆、上下文与独立评价的教学范围，但没有打包 AE26 原教材或延后开放的原参考答案。

提供的 Python 代码仅使用标准库，未安装新的依赖，未引用外部网络服务。作者完整实现与合法替代、语义坏实现、运行证据只在完整源码的 author 目录，不在本学生 ZIP 或试玩运行包。学生保留自己的实现和实验记录；不要把作者运行证据当成自己的掌握。

资料均为虚构，不描述真实港口、活动、个人或政策。手工向量与精确字段行是明示的有限实验：没有运行真实模型、embedding 服务、网络检索、现实来源认证、开放语义判断、多人服务或 Windows 真机验收。现有项目整体、角色和第三方组件的许可仍以游戏总许可清单为准，本说明不重新授权其他来源资产。
