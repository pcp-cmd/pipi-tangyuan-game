# 第七站：压缩后不丢约束，评分不听自夸

目标：按预算保留必要原记录，保持未解决状态；用独立标签和实际调用计数评价自己的程序。

## 先算一个会装不下的包

运行 `python examples/toy_walkthrough.py budget`。异题目标 `paint` 长 5、约束 `dry only` 长 8，两项共 13。预算 12 时唯一正确结果是明确装不下；不能为了返回成功就丢约束。可选笔记不是必要条件，放不下可以跳过。

records 的 id/text/source 对应身份、完整内容与来源。required_ids 由宿主给；正文自带 required=true 没有权力变成必需项。先验证 id 唯一、必需项存在，再把必需总长度与预算比较。余量按“从最新可选记录向前选，放不下跳过”分配，最终恢复原顺序。这样能保留时间关系，也不会截掉句尾的否定。

这里计 Python 字符数，只是可手算机制，不是模型 token 计费。预算不足可能要求拆任务或按需读资料，而不是偷偷改变事实。原始目标、约束和每问题证据状态保留；错误摘要说“都完成了”不能取代尚存的 conflict 或 needs_refresh。

## 给一个假满分打零分

候选报告写 `correct=True`，但值与事先固定的期望不同，你该相信哪边？先写两题期望，再运行候选；评分方保留标签，不传给 plan/propose。`grade` 比较实际字段、状态、引用与独立观察的调用数，忽略自报 correct。

在候选的 search/read/proposer 外面各包一层计数器，调用之前累加；报告里的 counts 只能与这些观察比较，不能自己证明自己。公开 Python 同进程实验不是针对恶意代码的安全隔离；不可信程序还需要额外运行环境。本工程没有承诺这个边界。

冲突报告也不能凭空列两个正确字符串就通过：每个活跃候选值都需要真正引用支持。unknown 不应夹带单一答案。报告多出一个未请求问题，也不能藏在总分之外。

## 手算检索指标

排名 `[wrong,right,right,extra]`，相关集 `{right,extra}`，k=3。先去重得到前三个唯一 id，命中 2，precision=2/3，recall=1。若只返回一个且命中，本课 precision=1，不用固定 k 作分母；没有返回为 0。相关集合空时拒绝计算这个指标，另设缺资料应拒答的任务。

评分标签来自原文与任务，不从排名反推。比较 keyword/vector/hybrid 时保留逐题结果、实际调用次数和真实测得的耗时；一处改善、一处退步不能只写平均分上升。耗时仅是这台机器的本地运行，不是网络模型延迟或收费。

## 公开题与独立迁移

公开自测可用来练习、排错，不能称未见过的考试。你看过第二语料并据此改策略后，它也已参与开发；要证明进一步迁移，应先冻结代码和预算，让另一个人固定新题及期望，再观察全部运行，包括失败。

独立应用：构造两个策略，一个精确词更好但漏掉别名，另一个修好别名却不检查更新。用相同题集与预算列出改善项、退步项和真实来源变化。不要修改期望去迎合新策略。
