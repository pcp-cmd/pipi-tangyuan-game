# 猫咪商店的价目表

皮皮要问鱼饼多少钱，不想先记住它排在纸单第几行。列表适合用位置找东西，价目表更适合用商品名找到价格。今天水壶在第二行，明天加了绳索，商品名仍是稳定的查询入口。

这种“名字对应一个值”的容器叫字典。花括号里每一项用冒号连接键与值，项之间用逗号分开。键在本课是商品文字，值是金币数。字符串键要带引号；不带引号会被当作变量名读取。

## 读取一格，修改另一格

普通Python例子先查看船只停靠的泊位。

```python
berths = {"晨风": 2, "海燕": 5}
print(berths["海燕"])
berths["远帆"] = 3
berths["晨风"] = 1
print(berths)
```

输出先是5，再是 `{'晨风': 1, '海燕': 5, '远帆': 3}`。方括号中的键用来定位。右边有赋值时，不存在的键会新增，已有的键会更新，不会把整份字典清空。

一个字典中同一键只有一个当前值。给晨风改泊位覆盖的是晨风这一项，不是添加第二条同名船记录。若业务要保存每次变动，应另存历史，不能指望字典自动记住旧值。

## 新商品不能挤掉旧商品

本课保留输入字典 `prices`。从它读取鱼饼价格给 `fish_price`，再新增地图价格12。起始鱼饼单价为8，但检查会替换成其他价格，还会放入不同的旧商品。重新写一份只有鱼饼和地图的字典，会丢掉原有绳索或船票。

鱼饼价格为0时，它仍是有效价格。不能因为0在条件中是假，就当作没找到商品。`prices["鱼饼"]` 在键缺失时会报 `KeyError`；`get` 可以在缺失时交回另定的默认值。当前输入保证有鱼饼，不需要自己把缺失与免费商品混成同一种情况。

先拿一份包含鱼饼和绳索的价目表在纸上标出“读取哪项”“新增哪项”“哪些项原样保留”。这是局部修改的合同，不是重建你记得住的几种商品。

## 缺货与免费分开记

另设计一个查询函数，输入价目表与商品名列表，按查询顺序返回 `(商品名, 是否存在, 价格)` 的列表。存在时价格可以是0，缺失时价格用 `None`。重复查询要保留，价目表不变。

用一件免费商品、一件普通商品和一个不存在的名字写期望。再问自己，单独用 `get(name, 0)` 是否还能分辨免费和缺失？

自行核对存在标记、0与None、重复查询和原表不变。新题把一次读取改为批量且带存在信息的结果，不能直接沿用原课的一个数值返回。
