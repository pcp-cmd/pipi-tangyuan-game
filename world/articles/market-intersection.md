# 两份清单共有些什么

皮皮的船要水和灯，汤圆的船要水和绳。共同采购应只列水。若把两份清单直接拼起来，会得到两船需求的总集合；若只检查其中一份内部有没有重复，又回答不了两船是否都需要。

先区分三个问题：物品出现过没有、出现几次、按什么顺序列出。本课只关心是否同时出现，重复次数不保留；最后要按字符串顺序输出。输入是字符串列表，结果仍要是列表。

## 集合回答“有没有”

集合 `set` 把相等的元素合成一个成员，不承诺原清单的先后次序。下面在普通Python中用书包演示去重和成员判断，还没有合并两份输入。

```python
bag = ["map", "rope", "map"]
names = set(bag)
print(len(bag), len(names))
print("map" in names, "lamp" in names)
print(sorted(names))
```

输出是 `3 2`、`True False`、`['map', 'rope']`。第一个长度说的是三次出现，第二个说的是两种东西。`in` 给出成员判断；`sorted` 把成员按可比较的值排成新列表，保证展示顺序。

现在把第二艘船的清单也想成一组成员。一个名称进入共同清单的条件，是在两组中都能找到。你可以使用集合的交集，也可以逐项检查，但必须同时处理重复和最终排序这两项责任。交集的 `&` 与并集的 `|` 含义不同，先在纸上圈出共有项再选操作。

## 同样的值，可能有不同的错误顺序

给 `a=['b','a','b']`、`b=['a','b','c']`，结果应是 `['a','b']`。返回 `['b','a','b']` 表示只做了成员过滤却没有去重；返回包含c的结果表示把任一清单出现的都收了进来；返回 `['b','a']` 又漏掉了排序。

任一清单为空就没有共同项。完全相同的两份清单也只按种类出现一次。字符串比较是Python自己的字符顺序，不等同中文拼音或人类词典顺序；本课不要求按拼音排序，也没有大小写合并规则，所以 `A` 与 `a` 保持不同。

不要为了方便把输入本身排序再当作工作区。虽然这题重点是结果规则，返回新列表能让调用者继续保留原采购次序。更重要的是不要把集合当计数表：买三份水与一份水在集合中没有区别。

## 这次共同的是数量

另做两仓共同可提供数量的报告。输入改成两份“名称到数量”的字典，只输出双方都有且数量均为正的名称，并给出两边较小的数量；结果按名称排成 `[名称,可共同提供数量]` 的列表。

用一边水3份另一边水1份、一边有灯另一边缺灯、双方某项数量为零来核对。解释为什么先转成名称集合仍不够，还必须回到原字典取数。自行保存数量与顺序两类证据；本课的通过记录不代替这道新题的验收。
