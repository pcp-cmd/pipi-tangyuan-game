# 找到有用的航海笔记

汤圆要查Python工具，笔记里有人写 `Python`，有人写 `python`。如果只比较原字母大小写，同一主题会被漏掉。但找到笔记后，玩家仍需要看到原来的文字，而不是一份全部变成小写的改写稿。

本课实现 `retrieve(notes, query)`。返回包含query的笔记，比较时忽略英文大小写。结果保留原文、原顺序和重复项；空查询匹配全部笔记。这里的“包含”是连续文字的字面包含，不是理解一句话的意思。

## 比较用的值与展示用的值分开

字符串的方法通常返回新的字符串。`lower()` 给出小写形式，不会把原来的名字原地涂掉。

```python
note = "Python Shop"
comparison = note.lower()
print(comparison)
print(note)
print("shop" in comparison)
```

输出是 `python shop`、`Python Shop`、`True`。`in` 在字符串上检查子串，在集合上检查元素，含义由参与的数据决定。先从这一个笔记的判断开始，再把规则用于整个列表。

查询也要做相同处理。只把笔记转小写，却拿大写的query来比较，仍可能漏掉命中。判断成立后应把哪个值放入结果？是用来比较的小写副本，还是要保留的原文？把两者写在不同名字下，有助于检查自己有没有混淆。

## 查询没有文字时怎么办

本课明确规定空查询匹配全部。Python中空字符串是任何字符串的子串，因此这条语义与字面包含一致。不要把空查询擅自改成错误或空结果。

同一段笔记出现两次也要保留两次，检索不负责去重。输入 `['A', 'A', 'b']` 与空查询得到三项，不能因为前面学过去重就顺手删除第二个A。

找不到任何命中返回 `[]`。输入本身为空也返回 `[]`。这两个结果相同，原因不同；调试时检查原始输入可以分清是没有资料，还是资料里没有目标字面。

英文小写化只处理当前比较规则。它不等于所有语言的身份规范化，也不能理解“灯塔停止开放”与“灯塔开放”的区别。字面命中提供候选资料，不证明资料支持某个结论。权限、来源版本和逐句核对在灯塔检索以及“档案馆·可复查的研究”工程中另做。

## 让两条关键词共同筛选

新任务接收两个关键词列表 `required` 与 `forbidden`。笔记必须包含所有required关键词，且不能包含任何forbidden关键词，比较仍忽略英文大小写。required为空时不增加正向限制，forbidden为空时不增加排除限制，结果保留原文与重复项。
