# 排队要说清第一条和第二条规则

出航名单先看分数，高分先走；同分时才按名字从小到大。只按分数排序会把同分处理交给原来的顺序，只按名字排序又会让低分的人越过高分的人。你需要表达规则的先后，而不是碰巧让一份样例排对。

输入每行是 `[名字,分数]`。先确认索引0读名字，索引1读分数。排序用的“键”是从一行计算出的比较值；它不替换原行，只告诉排序器如何比较。元组可以把多个比较值放在一起，先比第一项，只有相等才比下一项。

## 把两项优先级放在同一个键里

下面在普通Python中给货箱按重量从轻到重、同重按编号排序。这与本课分数方向不同。

```python
boxes = [("B", 4), ("C", 2), ("A", 4)]

def order_key(box):
    return (box[1], box[0])

print(sorted(boxes, key=order_key))
print(boxes)
```

输出是 `[('C', 2), ('A', 4), ('B', 4)]`，然后仍是原来的B、C、A顺序。C的首项2小于4，先被选中；A和B首项同为4，才比较编号。`sorted` 返回新列表，输入没有被就地重排。

本课分数越大越先，因此要把“高分先”的要求转换成键的比较方向；名字仍按升序。一个办法是想一想，数值取负后大小关系怎样改变。不要给整个元组简单加 `reverse=True` 就认为两项都正确，那会连同名字方向一起反转。

## 排好的行还不是最终答案

对 `[ ['pipi',8], ['tang',10], ['al',8] ]`，先确定行的次序是tang、al、pipi，随后才从每行取名字，形成名字列表。排序阶段还需要分数；若提前只留下名字，就丢掉主要比较依据。

同名不同分是两条记录，必须都保留。例如pipi有2分和4分两条，最终名字列表里应有两个pipi。先转字典或集合会把行合并掉，即使看起来“去重整齐”，也已经改变任务。空输入返回空列表。

用两个同分名字查第二规则，用两个同名分数查是否漏行，用全负分数查数值方向。Python排序是稳定的：键完全相等时保留原次序。但稳定性不能代替本课明确要求的同分按名字规则。这里的字符串顺序也不是拼音规则。

## 保留报名时间的分组排队

另做活动队列，每行包含区域、分数、姓名和报名序号，输入已按报名先后排列。要求先按区域升序，再按分数降序；同区域同分必须保留输入顺序，不用姓名或报名序号另作排序键。返回完整行，不只返回名称。

让两条同区域同分记录的名字次序与报名次序相反，并核对它们仍按报名排列。再检查跨区域高分不能越过区域规则。这个任务同时改变了平局责任和输出内容，需要你重新设计键与稳定性的分工。自核记录不会自动写入本课成绩。
