# 给工具取清楚的名字

码头量绳子，已知两个互相垂直方向的距离，需要直线长度。公式看起来只有平方、相加和开方，但很大或很小的浮点数会在中间步骤丢失信息。标准库已经提供了处理这些尺度的工具，不必重新拼一遍容易出错的公式。

模块把一组相关定义放在一起。`import math` 把数学模块绑定到math这个名字，之后用点号指明要取其中哪一个工具。这样读代码的人能看到操作来自哪里。

## 名字指向哪里，要能追得上

先在普通Python中调用另两个数学工具。

```python
import math
from math import ceil as round_up

print(math.sqrt(81))
print(round_up(2.1))
```

输出9.0和3。第一种写法保留模块前缀；第二种只导入ceil并给它取本地别名round_up。别名不改变函数含义，ceil是向上取整，不是普通四舍五入。

不要之后又写 `math = 3`，那会把同一名字改为指向整数，`math.sqrt` 就找不到原模块。大量星号导入也会让名字来源难以辨认。明确导入需要的名字，通常比猜当前作用域里有什么更容易排错。

## 直角绳长为什么交给hypot

目标 `rope_length(x, y)` 使用标准库 `math.hypot`。输入是绝对值不超过1e308的int或float坐标分量，负号表示方向，不会让绳长变成负数。它不是只对整数3与4写一个结果5。

`math.hypot(x, y)` 计算欧几里得长度，同时处理平方中间量的尺度。直接计算x平方加y平方再开方，面对1e308时中间量可能溢出；面对最小的正浮点量5e-324，平方可能先变成0，之后开方无法把丢失的信息找回来。

本课还包含小数方向与零向量。请解释函数的参数如何进入标准库调用，并用两端尺度检查。调用标准库并不意味着任意输入都合法，复杂数、非数值或无限值没有在这里作为输入合同承诺。

不要把这个例子扩写成安装外部数学包。math属于Python标准库，游戏已有运行环境支持本课所需工具。

## 路线由几段绳子组成

另写函数，输入一列二维坐标点，返回相邻点之间各段长度及路线总长。空列表或只有一个点时没有线段，总长为0；不能把最后一项自动接回第一项。

先用直线上的三个点预测各段与总长，再换成重复点和折线路径。你需要先得到相邻坐标的差，再计算每段长度；不能把每个点到原点的距离当成路线长度。

自核段数等于点数减1但不低于0、重复点产生零长段、输入不变。保存误把“到原点距离相加”的反例。该路线题由你自行验收，不因单段绳长通过自动完成。
