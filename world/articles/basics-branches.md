# 按风力选行动

港口不能同时宣布出航和避风。风力弱可以出航，稍强要等待，再强就进避风处。你要把连续的非负整数风速分成三个互不遗漏的区间，每次只交回一个行动。

你已会让比较产生True或False，也会从函数交回结果。接下来要让不同结果选择不同语句。`if` 的条件为真时执行下面的缩进语句；否则继续看 `elif`，前面都没选中时才执行 `else`。

## 条件有先后，命中就选这条

先用普通Python看售票处的排队提示，它不是风力函数。

```python
waiting = 4
if waiting < 2:
    message = "可以直接登记"
elif waiting < 5:
    message = "请等一会儿"
else:
    message = "请先取号"
print(message)
```

输出“请等一会儿”。程序先检查4是否小于2，否；再检查是否小于5，是。进入第二段后，不再进入这条链的else。

如果第二行也写成一个独立的 `if`，它就不是“前一个没命中才检查”。多个独立if可能执行多段。尤其当后面重新给同一名字赋值，先选好的结果可能被覆盖。

## 先画分界，再写函数

本课入口为 `wind_action(speed)`。小于3返回字符串 `"sail"`，3至5返回 `"wait"`，6及以上返回 `"shelter"`。输入是非负整数，每条路径都应交回一个字符串。

最值得先测的是2、3、5、6。3属于等待而非出航，6属于避风而非等待。把“小于3”写成“小于等于3”，只差一个字符，却把边界挪了一格。用0和20再检查两端区间没有遗漏。

若从宽条件开始，例如先判断“大于等于3”就立刻返回等待，较大风力也会被它接住，后面的避风条件没有机会执行。判断顺序要配合区间方向，而不是把几条看着正确的比较任意排列。

这里的三个词是接口约定，打印中文提示不能替代返回它们。负数、缺测值和真实海况的安全决策不在这个课堂模型中。

## 缺测时先别猜风速

`None` 是表示没有具体值的对象，可以用 `value is None` 明确判断。两个结果可用 `(提示文字, 是否继续)` 放成一个元组一起返回，逗号分开的是两个值，不是同一句文字。先处理None，才能避免把它直接与数字比较。

另设计一个警示函数，输入可能是非负风速整数，也可能是表示未收到读数的 `None`。未收到读数时输出“待确认”，收到读数时按你制定的两档阈值输出提示，并同时返回是否允许继续检查下一站的布尔值。

先说明缺测为何不能按0处理，再列缺测、阈值前一格、阈值本身和远超阈值四个案例。新题多了不同形状的输入及一对返回值，要先分清缺测，再做数值比较。
