# 在圆内，取决于你用哪一种数值比较

救援范围是以原点为中心的圆，边界上的点也算可达。点(3,4)到原点距离5，但直接把所有坐标平方并转浮点，可能在很大或很小的输入上把圆外看成圆内。

先分清几何规则与表示规则。几何上比较x²+y²与r²就能避免开平方。Python整数可以精确计算大整数的平方；浮点数有可表示范围和舍入。本课要求纯整数精确比较，正常浮点按math.hypot的舍入语义判断，超出浮点可表示范围时再按输入实际数值的整数比比较。

## 一条小边不能被大坐标吞掉

在普通Python中观察两种已经明确的比较。

```python
import math

big = 10 ** 400
print(big * big + 1 <= big * big)
print(math.hypot(0.3, 0.4) <= 0.5)
print(1e-200 * 1e-200 == 0.0)
print(math.hypot(1e-200, 0.0) > 0.0)
```

输出False、True、True、True。第一行的点(big,1)严格在半径big的圆外，整数平方保留了那一格差异。第二行说明本课普通浮点边界按hypot的舍入结果处理。第三行的小坐标平方下溢成0，第四行的hypot仍保留非零距离。

这四行不能用同一个未经区分的“精确公式”替换。把0.3与0.4都转成精确整数比再比较，得到的是另一套边界语义，未必与本课规定的hypot结果相同。反过来把巨大整数都转float，又会溢出或丢失加一差异。

## 按输入与结果选择计算路径

对每个点先看x、y和radius是否全是严格整数。若是，直接用整数平方比较，边界用小于等于。否则尝试hypot；可正常得到有限距离时，就用它与半径比较。不是先给每个数随意加一段容差，本题没有这种扩大救援范围的许可。

若坐标转换触发OverflowError，或hypot结果不再有限，不能直接判圆外：半径本身可能是更大的整数。此时把整数写成分母1，把有限float用as_integer_ratio写成整数比，将平方和与半径平方通过正分母交叉相乘比较。分母为正，不改变不等号方向；整个回退过程可留在整数运算里。

反例按层准备：`(1e308,1e308)` 对半径1e308应在外，不能让两个平方都变无穷后得出“无穷等于无穷”；`(1e-200,0)` 对半径0应在外；`(10**400,1.0)` 对半径10**400也在外；原点在半径0内。空点列表计数为0。

输入已限定有限坐标、非负半径且无bool，所以这课不要求为NaN或负半径另造规则。数量正确也不代表误差策略正确：只有普通小整数的几个样例，区分不出这些路径。

## 换成两个同心边界之间的点

另实现环形救援带统计：内半径边界排除，外半径边界计入；输出原始点索引，不能只给数量。沿用纯整数、正常hypot、超范围整数比三条数值规则，内半径不得大于外半径。

用原点、恰在内边界、恰在外边界、大整数相差一格和微小非零点验证。检查每个返回索引能对应输入点，并说明两条边界的不等号为什么不同。新题增加双边界与位置保留，不能照抄当前计数输出；自核不自动写入成绩。
