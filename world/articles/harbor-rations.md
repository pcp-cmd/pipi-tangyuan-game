# 潮汐前的补给

两只猫要在海上待3天，每天各吃1份鱼饼，总共需要6份。每箱放4份，一箱装不下，第二箱即使没有装满也得带上。装箱题计算的是箱子的个数，不是每箱平均分到多少。

本课的 `boxes(people, days, capacity)` 接收人数、天数和每箱容量。people与days是非负整数，capacity是正整数，返回足够容纳全部补给的最少整数箱数。合同已经保证容量不为0，不需要为不存在的输入另创一套规则。

## 商是完整的组，余数是剩下的份

你在算利润时用过乘法。这里先确认单位：人数乘天数得到需要准备的份数，再按每箱的份数分组。普通除法 `/` 给出比例，整除 `//` 给出向下取整的商，`%` 给出余数。

先在普通Python中分发17枚贴纸，每张卡贴5枚，只观察完整卡与剩余贴纸。

```python
stickers = 17
per_card = 5
full_cards = stickers // per_card
leftover = stickers % per_card
print(full_cards, leftover)
print(full_cards * per_card + leftover)
```

输出 `3 2`，然后是17。3张完整卡用掉15枚，还剩2枚。第二行把分组结果合回原总量，是检查商和余数是否理解正确的方法。

回到箱子：如果没有剩余，完整箱已经足够；如果还有剩余，就必须为它们安排额外空间。分别画出“刚好分完”和“还剩一份”，再组织函数，不要靠某一个示例答案推所有情况。

## 多一箱与少一箱都不符合最少

始终给整除结果加1，会把12份、每箱6份算成3箱，其实2箱正好。只用整除，则把1份、每箱8份算成0箱，连唯一一份都装不进去。people或days为0时没有补给需求，答案也是0。

不要先算浮点除法再向上取整。Python整数能精确保存很大的计数，浮点数却可能把相邻大整数合并。例如9007199254740993份、每箱1份，应当恰好需要同样多箱；转换成浮点后已经可能少记1份。先丢精度，再取整，无法找回那一份。

本课所有计数都为整数且容量为正，商与余数的解释成立。真实行李还受重量、易碎品或不可混装约束，那是另一份装箱合同，不能由这里的份数计算推出。
