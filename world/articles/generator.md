# 让物资按需到达

船长只想先看前三箱物资，仓库却先准备好全部一千箱，准备工作就比实际需要多。生成器让调用者要下一项时，才继续做生成下一项所需的工作。

你已会函数与循环。普通函数通常执行到return后交回结果；包含 `yield` 的函数调用后交回生成器对象。生成器是能逐项取值的迭代器，`next` 要一项，for也会反复索取下一项。

## 创建、取出、耗尽是三个时刻

下面的普通Python例子只有两张票，特意显示准备时机。

```python
def tickets():
    print("准备第一张")
    yield "A"
    print("准备第二张")
    yield "B"

stream = tickets()
print("已创建")
print(next(stream))
print(list(stream))
print(list(stream))
```

先输出“已创建”，这时函数体还没准备票。首次next才打印“准备第一张”，交出A并暂停。`list(stream)` 继续取剩余项，打印“准备第二张”，得到 `['B']`。再次取列表只得到 `[]`，它不会自动回到A。

暂停时，生成器保留这次调用的局部状态和执行位置。继续时接着走，不是从函数头重新运行。单独next一个已经耗尽的迭代器会抛StopIteration，for会把这个信号当作正常结束。

## 不预先做好，再假装逐件发

先补上循环所需的编号工具。`range(start, stop)` 给出从start开始、到stop之前的整数，默认每次加1；省略start则从0开始。它是可重复遍历的整数序列，不是生成器，也不必预先存放一整张整数列表。下面仍在普通Python中运行。

```python
print(list(range(4, 7)))
print(list(range(3)))
print(list(range(4, 4)))
```

输出 `[4, 5, 6]`、`[0, 1, 2]`、`[]`。这里用list只是为了显示完整例子，循环可以直接从range读取编号。起点已经到达停止位置时，没有任何一轮。

本课 `supplies(n)` 依次生成从1到n的平方。平方可以写成数乘自身或 `number ** 2`。n为0时没有任何项；每次重新调用supplies应得到独立的流。

`range` 的右端不包含在内，生成1到n时要自己检查起点和终点是否匹配。起始码只yield了0，既没有正确起点，也没有随n重复。

先创建完整平方列表，再返回它的迭代器，取值外观可能相同，却已经提前计算和保存整批数据。把完整列表藏在生成器内部再逐项yield，也没有解决这个问题。课堂会比较小输入和大输入只取前三项时的工作量，并查看是否保留大批集合。

生成器不是让任何程序都只占一点内存。调用者如果立刻list全部结果，最终仍要保存全部结果；这里承诺的是生成一侧不预先建立整批平方数。也不涉及并发、文件读取或后台生产。

## 从一条流切成小批次

另写一个生成器，接收只能走一次的输入流和正整数批量大小，每次交回一小批列表，最后一批允许不足。只有调用者继续要下一批时，才进一步消费输入。

先用能记录“取了第几项”的输入流，取第一批后检查只消费了这一批所需的项。再测空输入、刚好整批和末尾短批。每批应是独立列表，不能反复清空并复用同一个列表让此前结果也变化。

新题增加输入消费责任和输出对象独立性，不能只把平方公式改名。保存消费轨迹与批次内容自行核对，它没有接入原平方任务的自动成绩。
