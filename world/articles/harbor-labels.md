# 湿掉的行李牌

汤圆收到的行李牌写着 `"  Sea  MAP  "`。首尾空白来自录入，名字内部的两个空格却属于原文。清理时如果把所有空格都删掉，箱子的名字就变了。

`clean_label(label)` 接收字符串，去掉首尾空白并转成小写；清理后没有内容时返回 `"unknown"`。这两个英文单词之间原有几个空格，结果就保留几个。中文内容同样可以出现。

## 方法交回新文字，原文字不会跟着变

字符串是文字值。`对象.方法()` 调用这个对象提供的操作，括号表示实际调用。`strip()` 去掉两端空白，`lower()` 取得小写形式，它们都会返回新字符串。普通Python中用repr观察空白的位置，repr会显示引号和换行等转义。

```python
tag = "  North  Gate  "
trimmed = tag.strip()
print(repr(trimmed))
print(repr(tag))
print("ÉTÉ Straße".lower())
```

三行输出分别为 `'North  Gate'`、`'  North  Gate  '` 和 `été straße`。两次连续空格仍在；只调用strip而不保存它返回的值，也不会修改tag。

strip不只识别普通空格，还包括两端的制表符、换行和全角空格等空白。lower也不只处理英文字母。这里用小写规则，不做去重音、翻译或拼写替换。`Straße` 的小写是 `straße`，不是把ß替换成ss。

## 什么时候才知道牌子是空的

`""` 长度为0，`" "` 仍有一个空格。原文不为空，不能证明清理后还剩内容。`" \t\n"` 就是能区分这两种判断时机的输入。

你已经见过返回True或False的比较。`if 条件:` 在条件为真时执行下面缩进的代码，`else:` 处理另一条路径；if与else对齐，里面各缩进4个空格。`==` 比较相等，`=` 给名字赋值。放进函数时，整个分支又属于函数体，return会交回值并结束这次调用。

先取得准备使用的文字，再判断它是否为空。用明确的分支表达“有内容”与“无内容”，不要把只有空白的输入漏过去。

另一个反例是 `" A  B "`。先split再join会把内部两个空格变成一个，不符合只清理首尾的要求。对 `"汤　圆"`，内部全角空格也要保留。
