# 在每天之间放一个累计数

汤圆每天记一笔收入或支出，常被问“第2天到第5天一共多少”。每次重新加那几天，重复问一百次就反复读取同一批数。若先记住从开头到每个边界的累计值，两段累计相减就能去掉不需要的前半段。

你已在二分里见过半开区间 `[l,r)`：包含索引l，不包含索引r。这里prefix[k]表示前k项的和，不是第k项本身。prefix[0]对应一个数也没取，固定是0；因此输入n项，前缀表需要n+1项。

## 相减为什么刚好留下中间

在普通Python中观察一份已经算好的前缀表。本例只查询，构造表由你在本课实现。

```python
values = [4, -1, 6]
prefix = [0, 4, 3, 9]
print(prefix[3] - prefix[1])
print(sum(values[1:3]))
print(prefix[2] - prefix[2])
```

输出5、5、0。prefix[3]含前三项，prefix[1]只含第一项，两者相减剩索引1与2的和。左右边界相同代表空区间，两份累计相同，相减自然是0，不需要另取一个“第零项”。

建表时把“目前累计到哪里”当作状态。先保存空前缀0，每读一个新数，把它加到之前的累计值上，再保存新的累计。新增项保存的是总量，不是刚读到的增量。你可以用纸笔对3、-2、5追踪：边界0为0，边界1为3，边界2为1，边界3为6。

## 前缀不一定一直变大

支出用负数表示，累计值会下降，所以不能把前缀表误当升序数据直接做二分。两个0也是两次输入，前缀表要留下对应两个边界；把重复累计值去重会破坏索引与日期的对应。

空输入返回 `[0]`，不是空列表。少写开头的0会让区间从0开始时必须另作特判；多写一项或把单日值误作累计，也会让差分错位。排错时核对两个关系：长度是输入长度加一，每个相邻前缀差应等于对应原值。

建表花一次线性遍历，额外保存n+1个累计数；之后每次区间查询只取两项并相减。这并非不花成本的加速。如果原数据频繁修改，旧表就不再代表新数据，需要更新或重建；本课输入是一份给定的整数列表，不含在线修改协议。

## 同时知道区间总额与有效天数

另做观测表，输入每天的整数读数或None。允许重复查询一段日期的“有效读数平均值”，没有有效读数时返回None。为总量与有效数量分别建立可查询的累计信息，None不贡献任何一项，0贡献数量但总量增量为0。

检查全缺失、含0、负数和空区间；解释为什么只用一张总额前缀表无法区分“全缺失”和“两个相反读数抵消”。新题增加了两个累计状态与输出空值规则。请保存预测与结果人工核对，不自动写入本课成绩。
