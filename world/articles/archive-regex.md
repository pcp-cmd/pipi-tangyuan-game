# 通行证必须整张都符合格式

通行证印着AB-0123。前面多一个X、末尾多一行空白，仍含有那段熟悉的字符，但已经不是规定的整张证件。验证格式与在文章里寻找一个片段，是两种不同工作。

本课只接受两个ASCII大写字母、一个短横线和四个ASCII数字，返回bool。ASCII字母指A到Z，数字指0到9。全角数字看起来相似，也不在此范围。规则只验证外形，不证明号码真的由灯塔签发。

## 描述片段，再决定是否匹配整段

正则表达式中的字符类用方括号写出允许的字符，重复数量用花括号说明。下面在普通Python中验证另一种小标签，避免直接给出本课模式。

```python
import re

pattern = r"[a-c]{3}"
for text in ("abc", "xabc", "abc\n", "abd"):
    print(bool(re.fullmatch(pattern, text)))
print(bool(re.search(pattern, "xabc")))
```

前四行是True、False、False、False，最后是True。fullmatch要求整个字符串符合模式；search在任意位置找到片段就算匹配。返回的匹配对象或None再经bool转换，才是本课需要的布尔结果。

把当前通行证拆成三段：字母段、固定短横线、数字段。先分别说明允许字符和长度，再组合它们。不要用“任意字母”“任意数字”的自然语言猜某个简写含义：Python字符串正则中的 `\d` 默认能匹配Unicode十进制数字，范围比ASCII0到9更宽。

## 看起来像末尾，不一定是严格末尾

一种常见写法用 `^` 和 `$` 包住模式。但Python的 `$` 也可以匹配末尾换行之前的位置，所以只靠它可能接受本课禁止的结尾换行。使用整体匹配接口能更直接表达这里的责任。也不要先strip文本再检验，因为那相当于修改证件后才说它合规。

用 `AB-0123\n` 专门查整段边界，用 `AB-１２３４` 查ASCII限制，用 `aB-0123` 查大小写，用 `XAB-0123` 查是否误用了搜索。每个反例只改变一个条件，出错时更容易知道该修哪一项。

正则没有替你决定业务。若将来允许别的国家字母，或要求校验位，就需要重新定义格式与算法，而不是盲目把范围放宽。本课输入是字符串，不要求处理任意对象。

## 从验证转成带位置的提取

另写日志提取器，在多行文本里找出形如三个小写字母、冒号、两位ASCII数字的标签，返回每个标签及起止索引。要求标签左右不能紧贴字母或数字，标点或行边界可以作为分隔。

让日志同时含一个合法标签、一个嵌在更长单词中的伪标签以及两次相同标签。检查重复出现是否分别保留、索引是否对回原文、边界是否正确。这次要搜索并定位多个片段，不能继续对整篇日志做fullmatch。保存人工核对的索引证据；本课自动判题不覆盖它。
