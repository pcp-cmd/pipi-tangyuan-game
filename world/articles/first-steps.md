# 给冒险一个起点

皮皮站在码头，分支路口在前方 3 格。你要让程序记住这个距离，显示它，再发出相同距离的移动指令。这样，屏幕上的数字和皮皮收到的指令才是同一件事。

先看工作台已有的三行。它们按从上到下的顺序运行。

```python
steps = 1
print(steps)
game.move(steps)
```

第一行给名字 `steps` 一个值。现在这个值是整数 `1`，所以这份初始代码还不能完成 3 格的目标。

第二行读取 `steps` 当前的值，把它显示在输出区。第三行也读取这个值，交给游戏的移动操作。`print` 负责显示，`game.move` 负责提交移动指令。把文字打印出来不会让皮皮移动。

## 一个名字，为什么能在两处使用

`steps` 是你取的名字，程序可以通过它再次找到一个值。这种名字叫变量。`=` 是赋值，意思是先算出右边的值，再把左边的名字与这个值关联。

你可以把下面的例子当作整理鱼饼。读完后先在纸上写下两行输出，再核对。

```python
cakes = 2
print(cakes)
cakes = 5
print(cakes)
```

第一行输出是 `2`，第二行是 `5`。中间的赋值改变了后面读取 `cakes` 时得到的值。已经打印的第一行不会跟着变成 `5`。

程序的先后顺序因此有意义。若先读一个从未赋过值的名字，Python 不知道它指什么，会报告 `NameError`。检查名字拼写，也检查赋值是否写在使用之前。`steps` 和 `Steps` 是两个不同的名字。

## 引号改变了什么

汤圆的明信片上写着“前进三格”，那是给人看的文字。程序中的 `"steps"` 也是文字，它保留字母本身。没有引号的 `steps` 才会读取变量。

```python
cakes = 2
print("cakes")
print(cakes)
```

这段代码先显示 `cakes`，再显示 `2`。如果给数字加上引号，`"2"` 也成为文字。它看起来像数字，却不满足本课的整数要求。

括号告诉程序这次操作接收什么。`print(cakes)` 把读到的值交给 `print`。同样，`game.move(steps)` 把步数交给游戏提供的操作。你暂时不用学习如何定义这些操作，只要认出名字、括号和括号中的值。

普通 Python 中没有游戏提供的 `game`。上面的鱼饼例子可以在普通 Python 中运行，带有 `game.move` 的代码要放在游戏工作台。也不要把鱼饼例子作为本课答案，它没有完成移动任务。

## 回到码头，检查三件不同的事

这次任务要求 `steps` 保存整数 `3`，输出里显示这个数字，而且恰好提交一次前进 3 格的指令。

只把输出改成 `print(3)`，不能证明 `steps` 已经正确。只保留 `steps` 和 `print`，也没有移动指令。如果写两次移动，即使你想把它们凑成同样的距离，也不符合这次“一次前进 3 格”的约定。

先修改初始代码中保存距离的那一行。运行前，用手指依次指向三行，说出每一行会得到什么。再运行，打开检查明细，找出检查失败的是值、输出还是动作。游戏会先检查这次提交，通过后才结算它的课堂动作。

本课的移动操作每次接收 1 到 6 的整数。这个限制来自游戏接口，并不表示 Python 的整数只能到 6。当前任务进一步把距离规定为 3。

不要复制本课的 `steps` 三行。先写两次运行各会显示什么，再写程序。最后交换两条打印语句的位置，保持赋值不变，说明输出为什么改变了顺序、数量却没有互相交换。
