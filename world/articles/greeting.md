# 给汤圆一张明信片

明信片中“欢迎来到”总是一样，收件人和岛名却会变化。把整句固定写在程序里，下一位游客就会收到汤圆的名字。本课需要把固定文字与当前输入组合成 `greeting`。

前面已经见过带引号的字符串。引号是代码的边界，不会作为信中文字输出。变量 `name`、`island` 保存的是这次要填入的内容，而不是两个需要原样印出的英文单词。

## 花括号是填内容的位置

在引号前加 `f`，就能在字符串中用花括号放入要读取的表达式。这种写法叫f-string。普通Python例子先做一张行李牌。

```python
owner = "阿禾"
count = 2
tag = f"{owner}带了{count}件行李"
print(tag)
print("{owner}带了{count}件行李")
```

第一行是“阿禾带了2件行李”，第二行保留花括号里的文字。没有 `f`，Python不会把那两个位置当作变量读取。数字2放入f-string后，按显示形式进入文字；原变量仍是整数。

字符串在这一行执行时生成。之后修改 `owner` 不会追着修改已经生成的 `tag`。需要一张新牌时，应再次执行组成牌子的语句。

本课的两个可变部分分别来自 `name` 和 `island`。固定部分包含中文逗号和叹号。空格、全角“，”和半角“,”是不同字符，“看起来差不多”不能保证与要求的信件相同。

## 检查整句话从哪里来

保留原输入定义，让 `greeting` 读取输入。若换成“皮皮”和“珊瑚港”，姓名、地名都应跟着变化，只改其中一处仍不完整。若把 `"name"` 填进花括号的表达式位置，读取的是字面文字，而不是收件人的名字。

需要拼接的是文字，不是把两个输入互换。先分别圈出固定句段和两个插入点，再读一遍生成后的完整句子。本课输入已是普通文字，不要求网页转义、数据库拼接或用户身份验证。字符串格式化也不等于可以把陌生文字当Python代码执行。

## 为一批旅客发顺序号

这道扩展练习开始处理多项数据。方括号包住、逗号分开的名字构成列表，例如 `["阿禾", "小雨"]`。`for name in names:` 可以逐项读取，冒号后的语句缩进4格，每轮处理一个名字；用单独的整数记当前序号，用结果列表的 `append(...)` 在末尾存一张新牌。列表和循环会在“背包”与“贝壳”课继续展开。

另做一个普通Python程序，输入旅客名字列表，按原顺序产生一份行李牌列表，每张牌带从1开始的顺序号。名字可以重复，重复名字仍要拿到不同顺序号。空输入应产生空列表。

请先用 `['阿禾', '阿禾', '小雨']` 写出三张牌的期望内容，再设计逐项生成的方法。这里新增了一批输入、顺序计数和列表输出，不能只在原单张明信片上换字。
