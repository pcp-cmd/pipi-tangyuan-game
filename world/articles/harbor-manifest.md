# 启航许可证

装船登记里同时出现 `" 地图 "` 和 `"地图"`，应当只算一件名称；`"Map"` 和 `"map"`却是两种名称。许可证还要按第一次登记的顺序排列，不能为了去重把整张清单重新排序。

`manifest(items)` 接收列表，忽略非字符串，给字符串strip首尾空白，再忽略清理后的空名称，并按首次出现顺序去重，返回新列表。内部空白与大小写保持。调用结束后，输入列表不应被修改。

## 判断“见过”与保存“顺序”是不同的事

你已经会往列表末尾append，也会用for逐项读取。`in`可以检查一个值是否已经存在于容器里。集合set专门保存不重复的元素，适合记录见过哪些名称，但它不承诺替你保留登记顺序。

普通Python先观察集合的成员判断，只打印判断和数量，不依赖集合显示顺序。

```python
seen = {"Map"}
print("Map" in seen)
print("map" in seen)
seen.add("Map")
seen.add("map")
print(len(seen))
```

输出True、False、2。已有Map再加入一次，成员数量不增加；不同大小写仍是不同成员。创建空集合写 `set()`，而 `{}` 是空字典。

可以用结果列表本身判断是否见过，也可以另备一个集合帮助判断、仍由列表保存顺序。两种做法都要按原输入从前往后处理。先把每个步骤的职责说清楚，再选择容器，不必为了使用set而牺牲顺序。

## 清理前后，名字可能变成同一个

遇到None或整数3时先忽略，不能直接调用strip，否则这些值没有所需的字符串方法。`isinstance(item, str)`可以判断它是不是字符串；把所有东西先str转换，会把3变成名称 `"3"`，也就接受了应排除的项。

再看 `[' 灯 ', '灯', '   ']`。如果清理前先去重，前两项看起来不同，清理后就会留下重复的灯；空白项清理后则完全没有名称。因此去重比较必须面对最终准备保留的文字，空名称也不应该加入结果。

对 `['map  case', 'map case']`，内部双空格与单空格不同，两项都保留。不能沿用“湿掉的行李牌”课的小写操作，因为这里明确区分大小写。

返回新列表还包括空输入的情况。直接return items即使内容看似对，也让调用者拿到原对象；后续向结果append会改变原始登记。这课要求清理结果有自己的列表。

## 保留每个名字来自哪几行

新任务改为返回 `(清理后名称, 原始位置列表)` 的列表，名称仍按第一次有效出现顺序排列，原始位置从0开始。相同名称不再简单丢弃后续项，而是把位置补入已有记录。

例如 `[' 灯 ', None, '灯', '水']` 应保留灯来自位置0和2、水来自位置3。空白与非字符串仍忽略，但不能先过滤后重新编号，否则位置会错。

自核重复项、内部空白、大小写和空输入，确认每个位置对应原始清单且输入不变。这道题增加来源汇总结构，需要独立组织数据，保留你的结果自行对照。
