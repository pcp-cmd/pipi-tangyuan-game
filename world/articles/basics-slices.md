# 截取一段航行记录

手账要展示第1号到第3号位置之前的记录，展示时还要告诉读者它原来在整本手账的哪里。如果截出一段后重新从0编号，位置就会失真。

本课 `label_window(values, start, stop)` 返回一串 `(原索引, 值)`。输入位置是非负整数，可以超过列表长度；不修改原列表。先回忆索引从0开始，再学习两个边界怎样圈定一段。

## 右边界不包含在内

`values[start:stop]` 从start开始，取到stop之前，叫左闭右开的切片。下面可在普通Python运行。

```python
pages = ["港口", "集市", "工坊", "灯塔"]
print(pages[1:3])
print(pages[2:20])
print(pages[3:1])
print(pages)
```

输出为 `['集市', '工坊']`、`['工坊', '灯塔']`、`[]`，最后仍是原来的四项。stop超过长度会停在实际末尾，不像直接读取不存在的单个索引那样报错。start不小于stop时，这种正向切片为空。

取出的一段有自己的位置，但原编号没有自动附在值上。取出集市时，它在小列表里位置0，在原列表里位置1。把“新列表第几项”当“原来第几项”会丢失上下文。

## 编号要跟着位置走

`enumerate` 可以遍历时同时给出计数与当前值，默认计数从0开始，也可以明确指定起点。它的计数不是自动查询原列表的位置，你需要自己保持编号约定。

例如 `enumerate(["灯", "帆"], start=5)` 会依次交出 `(5, "灯")` 和 `(6, "帆")`。`for number, value in ...:` 能把每一对拆给两个名字；start=5是由调用者明确指定的编号，不是这两件物品原来在其他列表中的位置。

不要用 `values.index(value)` 回找编号。若输入为 `['港口', '港口', '工坊']`，两个港口是不同位置，index只找到第一个相等值。编号来自遍历的位置，不来自物品名字是否独特。

实现前用start=1、stop=3在纸上标出要保留的原编号。再测空列表、start超过长度和stop很大。本课不接收负边界或步长，Python切片的更广泛功能不能混入这里的输出规则。

## 两段记录，仍留来源

另写函数，输入一份记录及两个不重叠的非负区间，返回按区间给定次序排列的记录，每项带原索引和“第一段/第二段”的标记。区间顺序可能先晚后早，不能擅自按原索引排序。

用先取末尾、后取开头的例子预测输出，再加重复值与空区间。现在需要保存区间来源，不能只把两段值拼起来再从0编号。

自核原索引、段标记、输出顺序与原列表不变，保存自己的运行结果。这项组合切片不由原单区间任务自动判题。
