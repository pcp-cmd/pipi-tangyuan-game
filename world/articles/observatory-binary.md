# 同名货箱的第一箱

货栈已经按编号排好一排箱子。编号允许重复，新到的箱子要放在所有同编号箱子之前。皮皮不需要搬动箱子，只要交出应该插入的位置。

例如，现有编号是 `[2, 5, 5, 5, 9]`。新箱编号为 `5` 时，答案是索引 `1`。索引从 0 开始，第一个箱子的位置是 0。若新编号是 `7`，答案为 `4`，它应插在 `9` 前。编号为 `12` 时，答案为 `5`，表示放在队尾。

所以答案不一定指着一个已有箱子。长度为 `n` 的序列有 `n + 1` 个插入位置，包括最前和最后。空序列也有位置 0。

本课实现 `lower_bound(sorted_values, target)`。输入已经按升序排列，元素与 `target` 都是整数。函数返回最左插入索引。本课的大输入检查给你一个只读序列，2048 个数值最多读取 16 个，不能靠逐项扫描或先复制整段数据找位置。

## 先看懂可以跳过的部分

二分查找依靠排序带来的推断。假设你查看了中间箱，编号是 `4`，新编号是 `6`。中间箱左边的编号都不大于 `4`。这些箱子都小于 `6`，所以插入位置一定在中间箱之后。

如果中间箱编号恰好是 `6`，事情不同。左边可能还有编号 `6` 的箱子。此时停下，只能找到某一箱，无法保证找到第一箱。

在写循环前，先确认你能用列表索引读取一个值，能区分 `<` 与 `<=`，并能追踪 `while` 每一轮改变的变量。这里还要用到 `//`。对于非负索引，`(lo + hi) // 2` 会取两端中间的整数位置。

## 用两条边界记住尚未查清的区域

设 `lo` 和 `hi` 是两个边界。约定索引小于 `lo` 的数都小于目标，索引大于或等于 `hi` 的数都不小于目标。中间的 `[lo, hi)` 还没有分清。

这个写法包含 `lo`，不包含 `hi`，叫半开区间。`hi` 可以等于序列长度，表示右边还没有箱子，而不是要读取索引为 `hi` 的元素。

开始时 `lo = 0`，`hi = len(sorted_values)`。左右两段都为空，因此上述约定成立。每一轮都保持这个约定，它就叫循环不变量。这个术语描述一条你可以检查的事实，不是另一种 Python 语法。

注意两种范围的区别。尚未分类的元素在 `[lo, hi)` 中，而答案这个插入位置可能正好等于 `hi`。当 `lo == hi` 时，没有待分类元素，这个边界本身就是答案。

先在普通 Python 中运行下面的一次探查。它还不是完整解法。

```python
values = [2, 5, 5, 5, 9]
lo = 0
hi = len(values)
mid = (lo + hi) // 2
print(lo, mid, hi)
print(values[mid])
```

输出是 `0 2 5`，然后是 `5`。目标也是 `5` 时，索引 2 这一箱及右边的箱子都不可能位于“第一箱”之前。你可以把右边界收至这个位置，但还要保留它作为答案的可能性。

若目标改成 `6`，索引 2 的值小于目标，索引 0 到 2 都可以排除。下一轮左边界必须越过索引 2。只把左边界设成刚查看的位置，可能在只剩一个元素时一直查看同一格。

自己把两种比较结果写成边界更新。每写一条，回答两个问题。新的左右区域仍符合约定吗？待分类的元素数量 `hi - lo` 是否变小？两者都成立，循环才既正确又能结束。

## 跟着重复编号走完一次

对 `[2, 5, 5, 5, 9]` 查找 `5`，第一轮查看索引 2 的 `5`，右边界收至 2。第二轮查看索引 1，仍是 `5`，右边界继续向左。最后查看索引 0 的 `2`，左边界跨过它。两条边界相遇于 1。

答案来自整段数据的分界，而不是“遇到相等就返回”。你可以在纸上给每一轮写下 `lo`、`hi`、`mid` 和读到的值，再把程序输出的轨迹与纸上结果比较。

这个过程一次只读取中间一个数。待分类区域通常缩小约一半，因此长度翻倍不会让读取次数也翻倍。2048 项需要大约十几轮，本课允许 16 次读取。这个限制检查的是数值访问，不是墙上时钟的秒数。

不要在循环里为了显示方便而切片复制半段输入。本课会把切片取出的每一个数计入读取预算。写完手工追踪后，提交版本只需保留索引边界，不需要新的半段列表。只读序列也不承诺提供 `list.index` 或 `list.sort`。

## 用反例检查自己的边界

先预测，再运行这些输入。每个输入针对一个容易漏掉的条件。

- `[]` 中插入 `4`，答案为 `0`。循环体不能读取空序列。
- `[7, 7, 7]` 中插入 `7`，答案为 `0`。相等时不能提前返回中间位置。
- `[2, 5]` 中插入 `8`，答案为 `2`。返回值可以等于长度。
- `[2, 5]` 中插入 `4`，答案为 `1`。不存在目标时仍要给插入位置。
- `[2]` 中插入 `3`，答案为 `1`。最后一格必须被排除，循环不能停住。

如果输入没有排序，一次比较就不能保证另一半都更大或更小。例如 `[8, 1, 6]` 的中间值小于 `5`，却不能据此断言左边的 `8` 也小于 `5`。本课把“输入有序”交给调用者保证，不要求函数先扫描验证排序。先验证完整序列本身就需要读取全部元素，会违反这里的访问预算。

## 换成一段读数的数量

观测站发来按温度升序排列的整数读数，其中有重复值。现在要实现 `count_band(readings, low, high)`，统计满足 `low <= value < high` 的读数数量。

温度区间左边包含、右边不包含。若 `low >= high`，结果为 0。输入可以为空，不能改变输入。新程序同样只能按长度和索引访问，不能扫描后数个数，也不能把命中的整段复制出来。

先不要改本课的函数名后照抄。写清一个位置与一个数量有什么区别。你需要找到哪些分界，怎样把这些分界变成数量？用 `[1, 3, 3, 6, 9]` 的区间 `[3, 9)` 先算出期望值，再测试所有读数都在区间外、边界有重复值和空区间。

自行核对时，保留读取次数记录，并解释为什么输出是数量而不是某个索引。可以用一个只为核对而写的短扫描函数计算小输入期望值，再让正式实现处理大输入。核对函数的简便写法不代表正式实现也满足访问预算。

这道区间计数题没有独立的游戏自动判题，完成与否须另存代码、预测和运行记录。原题通过证明的是最左插入位置的合同，不能直接当作你已完成区间计数。
