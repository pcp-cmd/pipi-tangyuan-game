# 在规则变化的地方放测试

检票程序收到了7岁、10岁和15岁的旅客，全都收10元。三次正确并不能说明它会处理儿童或成人，因为这三个人都在同一个收费区间里。更多相似输入，未必提供更多辨别能力。

本课让你交出测试数据 `ticket_cases()`，每项是年龄和期望票价。规则是小于6岁免费，6至17岁10元，18岁起20元。年龄必须为非负整数，期望票价也必须为整数。你写的是规则的证人，不是被测检票函数。

## 用相邻输入分开两个近似规则

先在普通Python中看另一条运费规则：重量不超过3免运费，超过3收5元。

```python
def correct(weight):
    return 0 if weight <= 3 else 5

def wrong(weight):
    return 0 if weight < 3 else 5

for weight in (2, 3, 4):
    print(weight, correct(weight), wrong(weight))
```

输出为 `2 0 0`、`3 0 5`、`4 5 5`。只有重量3把两条规则分开。重量2和4也有价值：它们确认边界两侧归属，但无法单独揭露小于与小于等于的差别。

对于检票题，把年龄数轴分成三个区间，在每次收费变化两侧各取一个整数。原任务明确要求覆盖5、6、17、18四个边界年龄。不要把同一个比较符号从被测代码抄到期望计算里，否则程序和测试可能一起把边界写错。

## 每个样例要有独立的理由

一个边界错法把6岁仍算免费，另一个把18岁仍算儿童；用变化两侧能分别看到它们。恒收10元在儿童和成人上失败，恒收0或20也能被其他区间揭露。漏掉成人分支的实现可能在所有低龄样例上都正确，必须让测试真正走到成人区间。

样例里的期望不是候选函数运行出来的值。应先从题面独立算定，再与候选输出比较。若把错误候选的返回直接放进“期望”，任何实现都可以证明自己正确。也不要用非法负年龄去凑失败，那不在本课输入范围内。

你可以添加更多典型年龄，但不能省掉规定边界。返回结构要是一组年龄、期望成对的列表；只返回几个年龄，缺了判定依据。检查每个样例先接受正确规则，再问是否至少有一个样例拒绝每一种错法，两项责任缺一不可。

## 两个输入共同决定票价

独立设计带会员优惠的检票测试：基础年龄规则不变，会员只在需付费时减5元，免费儿童仍为0。测试输入现在是年龄与会员布尔值，期望仍是票价。

写出能区分“所有会员免费”“免费儿童扣成负数”“忘记成人会员优惠”的样例，并解释为什么只增加一个会员样例不够。核对边界年龄与会员状态的组合，不只各自测试一次。当前课只检查你交出的原票价样例，这份组合测试需要自行运行和人工审查。
