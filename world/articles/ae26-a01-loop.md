# 读完，再决定下一步

渡船助手先查主码头，发现今天停航，于是还要查备用码头。若第二次决定仍看不到第一次的查询结果，它可能一直重复查主码头。一次工具调用之后，程序必须把实际观察送回下一轮决定。

本课实现 `run(model, tools, max_steps=3)`。每次run都从新的空观察列表开始，每轮把累计结果的外层列表副本交给model。最多调用model共max_steps次。预算必须是严格正整数，布尔值不合法；非法预算在任何model调用之前抛ValueError。

## 把一轮结束时的事实带到下一轮

先用两份小列表观察什么叫累计与快照。

```python
observations = []
first_view = list(observations)
observations.append("主码头停航")
second_view = list(observations)
observations.append("备用码头九点开")
print(first_view)
print(second_view)
print(observations)
```

输出依次为空列表、一条观察、两条观察。每轮接到的副本反映那一刻的已知结果，后续追加不会替旧副本补内容。

如果在循环内部每轮都写 `observations = []`，下一轮会丢掉刚才的结果。如果把它建在函数外，又可能把上次任务混进新任务。列表应在本次调用开始时创建，跨本次各轮保留，下一次run重新开始。

工具的原结果本身不改写。副本只隔离外层列表，防止model重排或增删它时破坏宿主累计顺序；本课没有承诺把结果中的所有可变对象深复制。

## 每条路径都要有结束理由

合法final建议立即返回 `{"status": "completed", "answer": text}`，无需把预算用满。合法tool建议经过上一课的登记与调用规则，成功结果加入观察，再进入下一轮。

坏建议返回bad_output，未知工具返回denied，工具OSError返回tool_error，均为对应单字段状态并立即停止。其他程序异常继续传播，不能被“统一完成”盖住。空字符串是合法final回答，工具返回None或False也仍是应加入的观察。

预算计的是model调用次数，不是工具次数。例如先请求一个工具，再读结果后交回final，需要两次model调用。若预算只有1，第一轮工具执行成功后已经没有下一次决定机会，返回step_limit；不能为了“收个尾”再问一次。

输入检查也要在循环之前。`isinstance(True, int)` 会成立，但本课拒绝布尔预算，因此要按严格整数合同判断。预算0也不能先问一次再决定停止。

## 用事件记录分清先后

让假的model按它实际收到的观察决定下一步。先收到空列表时请求主来源，看到主来源停航后请求备用来源，看到备用结果才回答。不要只按调用次数机械返回一张事先排好的成功剧本，否则无法证明反馈真的影响决定。

分别用max_steps为1、2、3运行，记录每次model输入、工具调用和最终状态。再连续调用run两次，第二次第一次model输入必须重新为空。让model在收到副本后修改列表，确认宿主保存的已有结果没有被抹掉。

这仍是离线确定性函数，没有接真实语言模型。上限能阻止无限决定，不能保证决定有用，也不会撤销已经发生的效果。[可靠修补](../integration/engineering-labs/repo-repair/learner/README.md)要求你真实读取 Git 仓库、批准具体修改、观察修前失败与修后结果；[可靠派送](../integration/engineering-labs/durable-dispatch/learner/README.md)把草稿、批准、回执和新进程恢复接到真实 SQLite。它们需要实际代码与文件效果，不能靠给本课多加几轮调用完成。

[远航实践](../integration/engineering-labs/field-practice/learner/README.md)还有四件要亲手做的事：在本机记录正确目录、错误目录与恢复后的进程结果；对照受控工具拒绝和直接访问哨兵，辨认工具限制与操作系统隔离；在同一个任务上实现固定流程、决策循环和两个角色协作，记录实际事件；独立实现顺序预约与取消，并交付自己的测试和排错记录。这里的架构比较使用本地确定性程序，不能据此宣布真实模型或多 Agent 效果谁更好。运行环境、帮助来源、作品与真人解释要分别保存，打开工程或一次点击不会完成毕业。

## 为只读巡检增加停止条件

新巡检任务按需读取不同传感器。每次观察包含站点名与读数，同一站点在本次任务中最多读取一次；决策预算与工具读取预算分别计算。遇到重复请求要返回明确状态并停止，不能消耗一次真实读取后再说重复。

先画出“决定、检查预算与重复、读取、保存观察、再决定”的顺序。自行设计直接回答、两站成功、重复站点、读取预算先耗尽、决策预算先耗尽的案例。说清两种预算为什么不能共用一个数字。

这道迁移题改变了资源计数与历史约束，人工核对，不自动计入原课程。保留实际事件记录，不能只展示最后一句“巡检完成”。
