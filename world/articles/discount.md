# 做一个可复用的收银员

“打八折”和“减价20%”都让100金币的商品变成80，但这里的参数 `percent` 表示减掉的百分比。若把20当作要支付的百分比，方向就反了。先说清输入的含义，函数名本身不能替你决定它。

你已会乘法、减法和函数返回。百分比把一个整体分成100份，20%表示其中20份。Python的 `/` 做通常的除法，可能得到带小数的数；`//` 是向下取整，不能随手替代。

## 先算一块面积的比例

下面在普通Python中估算花圃，演示百分比，不计算商品折后价。

```python
garden = 60
flower_percent = 25
flower_area = garden * flower_percent / 100
print(flower_area)
print(garden // 8)
print(garden / 8)
```

输出15.0、7、7.5。第一行表示60中的25%，不是扣完以后的剩余。后两行说明整除会丢掉通常除法的小数部分。

折扣任务要交回的是剩余价格。先决定原价里减掉多少，或决定还保留多少比例，再由参数组织计算。不要把花圃例子原样改名当答案，它算的是被选中的那一部分。

## 每次调用，使用这次的价格

实现 `discounted(price, percent)`。0%减价应保留原价，100%减价应为0，50%减价应为原价的一半。价格可能有小数，例如7.5；本课按普通数值算出结果，不要求四舍五入成整数金币。

把结果写成 `price - percent` 会把百分比当固定金币数。商品200金币、减价10%，减少的是20而不是10。只在100金币上试验，会掩盖这个错法。

函数体里的 `print` 不能替代 `return`，调用者需要拿到数继续结账。也别在函数内部把 `price` 重设成100，让所有客人都按同一个原价计算。

本课输入范围是给定数值价格和常见0至100的减价比例。浮点结果可能有细微表示误差，课堂用数值容差检查；真正货币系统还要另定最小单位、舍入方向和时间点，不由这课自动提供。

## 两次优惠与一次优惠一样吗

另写程序比较两种结账过程。一种先减价10%，再对剩余价格减价20%；另一种只减价30%。返回两种结果及它们的差，而不是只有一个价格。

先拿200金币手算，说明第二次百分比以哪个金额为整体。再用零价、第二次减价0%和100%作检查。不能把两个百分数直接相加后宣称两次优惠总等价。

保存手算、实现和输出，自行核对两个过程的不同。这题新增了运算次序与中间金额的责任，原折扣函数通过只证明单次折扣合同。
