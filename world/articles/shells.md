# 把贝壳一枚枚数清

海滩四处的篮子分别装着3、5、2、4枚贝壳。只看最后一篮会漏掉前面的，只数篮子又得不到贝壳数。你要在走过每个篮子时，记住到目前为止已经数了多少。

前面已经会读列表、做整数加法。这里再学重复执行同一组步骤。`for count in shells:` 会按顺序从列表取值，每轮把当前值交给名字 `count`。冒号后缩进的语句是每轮要执行的循环体。`pass` 是空操作，不会帮你计数。

## 先看每一轮拿到了什么

这个普通Python例子只读三桶水的标签，不把它们相加。

```python
buckets = [2, 0, 6]
for amount in buckets:
    print("这一桶", amount)
print("看完了")
```

依次输出“这一桶 2”“这一桶 0”“这一桶 6”，最后输出“看完了”。0也是列表中的一项，所以循环体照常执行。最后一行没有缩进，只在整个循环完成后执行一次。

贝壳题需要多记一个量。开始前还没有数过任何篮子，累计值为0。数完第一篮应为3，第二篮应为8，第三篮为10，最后为14。每一步使用上一轮的累计值和这一轮刚拿到的数量。

这类跨轮保留的信息叫累计状态。名字 `count` 会换成下一篮的数，`total` 则必须带着之前的总和继续。把 `total` 每轮直接改成 `count`，最后只会留下4。把初始化放在循环体内，前面数过的又会被清零。

## 空海滩也要有确定答案

工作台保留 `shells` 的输入定义。在循环外设置起点，在循环内更新。这里要求实际执行循环，不是把14填进结果，也不是只调用一个现成总和函数。文章只解释累计关系，完整循环由你在初始代码上组织。

用 `[2, 0, 7]` 跟踪三轮，累计应经过2、2、9。再用空列表。空列表没有任何一轮，最终应仍为初始总量0。若累计变量只在循环体里建立，空列表时它根本没有得到值。

循环遍历的是给定列表。这里不需要边数边往同一列表添加项，那会改变未来能读到的内容。也不要把0当作“没有篮子”，一个数量为0的篮子与没有任何篮子是不同的数据形状。

## 每走一步，留一张小票

另写程序处理每个补给点收到的饮水数量，返回一份“到各站为止的累计量”列表。输入 `[4, 0, 3]` 应得到 `[4, 4, 7]`，空输入得到空列表，原输入保持不变。

这次不只输出终点总量。你要决定每次更新累计之后何时把它记进新列表。若先记录再相加，第一张小票就会错误地写成0。
