# 逗号不一定隔开两列

收货表里的商品可以叫“红,蓝旗”，还可能把名字写成两行。若把每一行按逗号切开，旗子会被拆成两件商品；若先按换行切开，又会把一个名称拆成两张收据。格式中的标点有自己的含义，不能与内容里的标点一律处理。

你已经学过收据累加和文本文件。这次先把“读懂一张表”与“把数量加入账本”分开。CSV的引号标出一个完整字段；引号内的逗号或换行属于字段内容。Python的 `csv.reader` 会按这套规则逐条交出字段列表，`StringIO` 则让内存中的文本像文件一样被读取。

## 先观察读表得到什么

下面在普通Python中只读取一份座位表，没有实现本课的商品汇总。

```python
import csv
from io import StringIO

text = 'seat,note\nA1,"near, window"\nA2,"two\nlines"\n'
rows = list(csv.reader(StringIO(text, newline=""), strict=True))
print(rows[0])
print(rows[1])
print(rows[2])
```

三行输出分别是 `['seat', 'note']`、`['A1', 'near, window']` 和 `['A2', 'two\nlines']`。最后的 `\n` 是列表显示字符串时写出的换行标记。表在文本中跨了多行，读取器仍把A2交成一条两字段的记录。

`strict=True` 要求读取器报告它识别到的坏CSV格式。本课包括未闭合引号，以及关闭引号后又接普通字符。读取器遇到这些错误会抛 `csv.Error`；你的工具对外约定统一抛 `ValueError`，因此应在格式边界转换这个预期错误，而不是把所有异常吞掉后返回空账本。

## 格式正确，数据也可能不合规

本课 `csv_totals(text)` 的首条记录必须恰好是 `item,qty`，顺序、数量与字段名都要匹配。后面的有效记录必须恰有两字段。`a,2,extra` 不能只取前两项假装成功；`a` 也不能自动补零。先验证结构，才有可靠的名称与数量可用。

商品名称用原文作为键。只用 `strip()` 判断是不是全空白，不能把清理后的名字存回去。例如 `" A "` 与 `"A"` 是两个名称。数量按 `int` 的整数文本规则转换，因此 `+4`、`１２` 可以得到整数，`3.5` 不能。负数在此表示退货，不要擅自拒绝；相加后是零的商品也仍保留。

一张表里依次出现“灯,3”“灯,-3”“绳,2”，账本中灯的状态经历3再到0。只把最新数量赋给名称，会丢掉上一张收据；只保留正数，又会丢掉一次完整抵消的记录。空数据但有合法表头得到空字典，完全空文本则连表头也没有，应失败。

排错时先看错误在哪一层：CSV拆分错误、字段结构不对、数量转换失败，还是累计状态不对。不要为绕过引号错误手工删引号，那会改变商品本身。

## 换成两类记录的旅行表

另写一个读表工具，表头是 `kind,name,value`。`kind` 为 `expense` 时把整数金额累加到旅行者名下；为 `note` 时把原文备注追加到该旅行者的备注列表。未知类型、字段数量不对或坏金额都让整次处理失败。

先设计一个备注含逗号的样例，以及同一人两次费用加一条备注的样例。检查金额与备注走不同处理分支、负费用按约定抵消、名字保留原文、遇到最后一条坏记录也不交出半份成功报告。你需要根据记录类型组合两种状态，不能只把本课表头换个名字。保存输入、期望与结果自行审查；此迁移题没有接入游戏自动成绩。
