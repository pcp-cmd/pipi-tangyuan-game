# 看清文字和数字

登记员从纸签读到“12”，仓库又送来3箱。要得到15箱，先要知道“12”是写在纸上的文字，还是已经能做整数运算的数。外表相近不表示程序会按同样方式处理。

本课接在变量与返回值之后。一个表达式会算出一个值，值具有类型。整数适合计数，字符串适合保存原样文字。`+` 对两个整数做加法，对两个字符串做拼接；它不会替你猜业务意图。

## 在纸签与计数之间转换

下面可在普通Python运行。先看两种加号各得到什么。

```python
label = "07"
print(label + "2")
number = int(label)
print(number)
print(str(number))
```

三行输出依次是 `072`、`7`、`7`。`int` 按整数文本解析，结果不保留前导0的写法。`str` 给数值生成文字形式，不能恢复输入原来有没有0或空格。

还要认识本课返回的容器。`(value, text)` 把两个结果按顺序放在一起，叫元组。调用者能区分第一项的整数和第二项的文字。不能因为打印时看起来都像7，就把两项都变成字符串。

## 用同一份结果生成两个出口

入口 `describe_count(text, extra)` 中，`text` 保证是合法整数文本，`extra` 已是整数。它需要先完成数值计算，再返回计算后整数及该整数的字符串。起始代码的 `(0, "")` 只是占位，不随输入变化。

用文字“ -4 ”与整数6在纸上追踪。先去理解整数转换后得到负4，再做运算，最后的两个结果必须表示同一个数量。若直接在文字后追加“6”，得到的是一段字符，不是数量。

混用字符串和整数做 `+` 通常会报 `TypeError`。看到它时，先标出两边的类型，再决定在哪个输入边界转换。不要为了消除报错把所有东西都转成文字，那会让程序能运行却计算错误。

这里不用负责解析“半箱”或“3.5”这类不满足合同的输入。`int("3.5")` 会失败；先转float再转int并不是本课约定的整数解析，会引入截断等另一套规则。
