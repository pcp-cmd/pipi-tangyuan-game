# 数清嵌套的货箱

大箱里装小箱，小箱里又可能装几枚金币。只数最外层会把里面漏掉，试着把列表直接加到整数上又会报错。你需要对两种输入分别说明怎么办，再把小结果合起来。

`sum_crates(tree)` 的输入要么是整数，要么是只含整数和列表的嵌套结构，深度不超过20。它返回所有整数之和，空列表为0，原输入保持不变。

## 自己调用自己，也要有结束位置

一个函数处理问题的一部分时再次调用同一函数，叫递归。先看普通Python中的简短倒数，它不处理货箱。

```python
def announce(n):
    if n == 0:
        print("到站")
        return
    print(n)
    announce(n - 1)

announce(3)
```

输出3、2、1和“到站”。n为0时直接结束，这叫基本情形。其他情况使用更小的n，所以最终会到达它。若递归时仍传原来的n，就不会更接近结束。

每次调用都有自己的参数和局部名字。内层返回后，外层才继续剩余步骤。处理树时，整数叶子不需要继续展开，列表则需要逐个处理自己的子项，再组合子项结果。

## 空箱与零金币，值相同但结构不同

空列表里没有子项，合计自然是0。整数0本身是一项数值，也贡献0，但不需要遍历。判断结构不能只看真假，因为0和空列表都为假，却应走不同的解释路径。

对 `[1, [2, [], [-3]], 4]` 手画几层。负3也参与求和，空箱贡献0，最终是4。若只在最外层累加，遇到子列表就无法继续；若把负数当坏箱丢掉，又会算成7。

本课允许递归，也允许自己维护待处理项的显式栈。不要通过pop输入列表来取项，否则调用者的树会被破坏。若用栈，要建立属于自己的一份待处理容器。

这不是任意Python对象的遍历器。合同只有整数和列表、有限深度，没有环形引用；Python递归也有深度限制，不能把当前深度20的成功说成能处理无限嵌套。
