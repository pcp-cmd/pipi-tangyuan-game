# 渡船售票口

同一条船，5岁和6岁的乘客票价不同，17岁和18岁也不同。售票员需要的是一套每个年龄只落入一段的规则，不能把“小孩子优惠”当成模糊判断。

本课实现 `fare(age, base)`。年龄小于6免费，6至17半价，18岁起全价；age非负，base是偶数整数，返回整数票价。价格从参数base取得，不能记住起始例子中的20或24。

## 前面的条件没通过，后面的才有机会

比较表达式决定一个条件是否成立，if/elif/else把互斥的几种情况排列起来。先在普通Python观察候船区剩余座位的提示，不计算票价。

```python
remaining = 8
if remaining == 0:
    message = "已满"
elif remaining < 3:
    message = "座位不多"
else:
    message = "仍有座位"
print(message)
```

输出“仍有座位”。先看是否为0，不是，再看是否少于3，也不是，最后才进入else。把remaining改成2，第二段命中；改成0，第一段命中后就不会再执行elif。

if、elif、else的行尾都有冒号，内部各缩进4个空格。它们放在函数内部时还要整体缩进一级。若分支内执行return，这次调用立即结束，不会继续执行后面的普通语句。只print票价却不return，调用者拿到的是None。

用这个执行顺序分析年龄：进入后面的区间，意味着前面的条件已经没有命中。你可以从低年龄到高年龄检查，也可以反过来，只要每个边界归属清楚，并且最终交回一个整数。

## 年龄边界和数值类型都要核对

把免费条件写成“小于等于6”，会让6岁免费；把半价结束写成“小于等于18”，会让18岁仍打折。分别用5、6、17、18测试，不要只挑中间的10岁。

半价也有类型要求。对整数24，`24 / 2` 得到浮点数12.0，`24 // 2` 得到整数12。本课base保证是偶数，因此二分后没有半个金币；不能据此决定真实奇数票价该向哪边取整，那需要另定规则。

零票价同样允许，免费、半价和全价都应得到整数0。高龄仍属于本题全价区间，不能自行添加老年优惠。这课计算一次票价，不负责收款或保留票据。

## 一家人的票要分别列出来

新任务输入一组年龄和偶数原价，返回每位乘客的票价列表与总票款。再增加一个规则：若所有乘客中至少有两位未满6岁，整单额外减2金币，但总额最低为0。单张票价列表仍保留减单优惠前的价格。

先把“每个人的区间”与“整组人数触发的优惠”分开，再说明总额来自哪一份列表。空家庭返回空列表和0。

自核恰好两位免费儿童、只有一位、18岁边界、零原价，以及额外优惠大于票款的情况。不要把整单优惠摊进每张票而改写输出含义；这份组合题需要自行保留运行证据。
