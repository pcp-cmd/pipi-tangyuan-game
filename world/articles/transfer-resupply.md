# 缺六件，不是订六箱

仓库已有2盏灯，目标8盏，缺6盏。每箱4盏，买一箱不够，买两箱才满足目标。多出的2盏是整箱限制带来的结果，不代表缺口算错。另一种货不能拿灯箱剩余的位置混装，本课每种名称分别装箱。

你已会计算缺货和整箱数量。这次要把它们组合起来：先按名称找正缺口，再把每个缺口转成足够覆盖它的整箱数。stock和target数量非负，pack_size是正整数，库存缺键按0处理，两个输入字典都不能改。

## 商与余数说明最后一箱是否需要

普通Python中先看纸张分包，不实现本课字典处理。

```python
sheets = 14
capacity = 5
full, leftover = divmod(sheets, capacity)
print(full, leftover)
print(full * capacity, (full + 1) * capacity)
```

输出 `2 4` 和 `10 15`。整除得到两包，余4张还没装进去，因此要再有一包。若余数为0，就不需要额外一包。这个判断完全使用整数，不必先转成浮点再ceil。

本课包含很大的整数。对10**40这样的数量，浮点可能已经无法分辨相差一件的两个数；先做 `/` 再向上取整可能得到错误箱数。用整数商与余数，或从整数不等式推导等价公式，可以保留边界。别把为非负缺口设计的公式直接用于负缺口。

## 先问有没有缺口，再问装几箱

库存比目标多或恰好相等时，不下单，结果中没有该键。库存里独有而target没提到的货，不属于本次补足目标。目标里新增绳1件而库存无绳，就按缺1件处理；即使箱子能装很多，也至少要一箱。

灯缺3件、水缺1件，每箱4件，必须分别下一箱，不能把两个缺口相加后说一箱就够。这是“按物品独立装箱”的约定，不是算式优化可以改变的东西。空目标得到空字典。

用一件差额、恰好整箱、比整箱多一件、零缺口、富余和巨大数量分别核对。对于每个输出箱数k，都应满足装得下缺口，并且少一箱就装不下；这两条一起说明既足够又没有多订。无需逐箱循环模拟，巨大数量下那会做许多重复工作。

## 每种商品的箱子大小不同

另写补货计划，输入增加名称到箱容量的字典，同时每件商品有每箱价格。输出每种商品的箱数、到货后库存与整单费用；目标里缺少容量或价格的商品必须报告配置错误，不能默认为0。

安排灯每箱4、水每箱6，并让一件商品刚好整箱、另一件多一件。核对到货后都达到目标，费用按箱而非按件累计，缺配置不交出半份成功计划。新题增加按名称配置与成本汇总，需要独立设计。人工核对不自动登记成绩。
