# 命令行解析也是函数输入

工具收到 `['--name', 'sea map', '--count', '0']`，应该把它变成结构清楚的配置。`sea map` 已经是一项参数，不需要再按空格切开；0也是合法次数，不能被默认值1盖掉。

你已经会转交参数和处理坏输入。这里的argv是调用者给出的字符串列表，不是从真实进程里读取的参数。解析器先识别选项，再把值转换成所需类型，最后才检查业务范围。把三个步骤混成字符串拼接，会让选项次序或带空格的名字出错。

## 声明选项与实际读取分开

下面在普通Python中解析一组与当前任务不同的参数。

```python
import argparse

parser = argparse.ArgumentParser(add_help=False)
parser.add_argument("--port", type=int, default=7)
parser.add_argument("--quiet", action="store_true")
options = parser.parse_args(["--quiet", "--port", "0"])
print(options.port, options.quiet)
```

输出 `0 True`。`add_argument` 先登记规则，`parse_args` 再处理明确传入的列表。`type=int` 负责把文本转成整数，`store_true` 表示出现开关就记True，不需要跟一段“True”文本。解析结果是有属性的Namespace，最后可把需要的字段整理成字典。

本课 `--name` 必填，`--count` 默认1且必须非负，`--upper` 出现时对名字调用upper。类型转换成功还不代表业务合法：负整数能被int读取，但不符合非负次数。不要用 `count or 1` 选默认值，默认值只在选项缺席时适用。

## 失败不能把宿主程序退出

argparse本来面向独立命令行程序，默认错误流程可能打印用法并抛SystemExit。本课是嵌在游戏里的解析函数，坏输入统一要抛ValueError。你需要把解析器的预期错误出口改为这个异常，或在明确边界转换它，不能让进程退出。

`exit_on_error=False` 可让解析错误由调用者处理，但它不会自动把错误改成本课要求的ValueError。还要处理解析器默认的帮助选项，因为帮助动作也会退出；这个函数只接受题目列出的业务选项，可以关闭自动帮助。请分别验证缺名字、缺选项值、坏数字、未知选项与负次数，而不是只试一次小数失败。正常选项可换顺序，argv原列表也要保持原值。

遇到名字含空格却被拆开，检查有没有把argv先join再split。遇到次数0变1，检查默认值是否靠真值选择。遇到正确样例总在读到别的参数，检查有没有漏传 `parse_args` 的输入而读了宿主命令行。

## 从文本选项生成一份可复查的执行计划

另写导出计划解析器，接受重复的 `--include` 名称、一个 `--format`（只能为json或csv）及 `--dry-run` 开关。输出包含按输入次序保留的名称列表、格式和是否仅预览，不执行任何导出。缺少include或未知格式都用同一种普通异常告知调用者。

检查重复项顺序、带空格单项、开关缺席、坏选项和输入不变。此题新增重复选项与枚举值约束，不能照抄单个name字段完成。自己保留测试列表与期望配置，它不由当前游戏判题登记。
