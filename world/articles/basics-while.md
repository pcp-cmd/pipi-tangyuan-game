# 遇到停牌再停下

港口的数量记录按到达顺序排列，负数标记代表“后面的记录暂不计入”。遇到第一个负数就停止，而不是挑出整份记录中的所有非负数。先把这两种规则分清，再选循环。

你已经会逐项取列表值、累加和比较。本课入口 `before_stop(values)` 接收整数列表，交回第一个负数之前的总和。0仍是数据，输入列表必须保持不变。

## 每一轮都要更接近结束

`while` 在每一轮开始前检查条件。条件为真才执行缩进的语句，执行后回到条件。下面的普通Python例子只做倒数。

```python
remaining = 3
while remaining > 0:
    print(remaining)
    remaining -= 1
print("可以关门")
```

输出3、2、1，然后“可以关门”。`-=` 在这里把目前的整数减1，再保存回同一名字。若漏掉这一步，条件会一直为真。先说出改变的是哪个状态，才知道循环为什么能停。

对列表使用位置时，也要让索引逐步增加，并在读取前确认还没超过长度。`break` 会直接离开当前一层循环，不再处理后面的项目。它与“跳过这一项继续走”不同。

## 一张停牌会挡住整个后段

对 `[2, 0, -1, 8]`，答案是2。0不增加总数，但不让行程停止；负1不计入；它后面的8也不能计入。先筛掉所有负数再求和会得到10，改变了停牌的意义。

如果第一项就是负数，还没有数到任何有效项，应交回0。空列表也是0。没有负数时，全部项目都要处理。累加状态在开始时建立，不应靠读到某一项才有值。

可以用while和索引，也可以用for加break表达停止。不要用删除列表首项的方式推进，因为调用者还需要完整原记录。起始码只有初始总量与return，仍需由你加入读取、停止和更新的顺序。

## 停止以后，留给下一班处理

另写一个函数，返回两部分。第一部分是停牌之前的总和，第二部分是停牌之后尚未处理的列表，不包含停牌本身。如果没有停牌，第二部分为空列表。原输入不变。

先用 `[3, -2, 7, 0]` 写出两部分的期望，再测停牌在第一项、最后一项及空输入。现在除了总量，你还要保留停止位置和剩余资料，不能只把原来的结果改成列表。

这是自行核对的应用。保存停止位置、每轮总量和剩余内容，说明停牌为何不出现在任何一部分。游戏原题通过不会自动验收新返回合同。
